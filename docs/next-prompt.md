# Полный паритет с Clojure LSP

Начни с [AGENTS.md](../AGENTS.md) и [матрицы паритета](design/lsp-parity.md).
Сохрани текущие правки. Используй закреплённый пилот и сравнивай одинаковые
запросы, результат правок и поведение на несохранённых буферах.

- Запусти `just lsp-parity` и выбери недостающий сценарий. Добавь рабочий
  протокол и тест поведения. Одна декларация capability сценарий не закрывает.
- Развивай редакторские функции в `parenox-lsp`, семантику исходников в
  `parenox-analysis`, форматирование в `parenox-formatter`.
- Продолжай тайпчекинг на настоящих spec. В пилоте с `lsp4clj` остаётся
  [`any?` в аргументах команды](design/type-checker-research.md#range-formatting-and-the-identity-predicate).
- Запусти `just verify`, проверку соответствующего сценария на пилоте и
  `just agent-loop`. Обнови матрицу по результатам.
